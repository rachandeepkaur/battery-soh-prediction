- `03_modelling.ipynb` and `04_tuned_and_extra_models.ipynb` used features measured inside the target discharge (for example `chg_CC_V0`), which leak the SOH answer. Their errors (about 2.0 SOH points) are too optimistic. They are kept to show the effect of leakage.
- `samina_regression_pilot_2_009.ipynb` is the early one-cell pilot with a preliminary SOH estimate.

Final results: notebooks 05-09 (evaluation protocol, models, comparison, classification).
